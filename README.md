# Wishlist подарков на день рождения Темы

Минимальный и аккуратный MVP-проект для семейного списка подарков.

## Что умеет проект

- Показывает фиксированный список подарков в таблице.
- Позволяет ввести имя и забронировать подарок.
- После бронирования подарок становится недоступен для других.
- Показывает имя человека, который забронировал подарок.
- Сохраняет данные в локальной SQLite-базе между перезапусками.
- Защищает от двойного бронирования на сервере (через условное обновление записи).

## Стек и почему он выбран

Используется **Node.js + Express + SQLite (sqlite3)**.

Почему это лучший вариант для данного MVP:

- минимум файлов и зависимостей;
- простой запуск локально;
- надежное хранение в одном файле базы;
- легко читать и поддерживать без оверинжиниринга.

## Быстрый запуск

```bash
npm install
npm start
```

После запуска откройте:

- `http://localhost:3000`

## Полезные команды

```bash
# Запуск в режиме разработки (автоперезапуск)
npm run dev
```
